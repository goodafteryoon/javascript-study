# 제너레이터/이터레이터 - 제너레이터: 이터레이터이자 이터러블을 생성하는 함수 ##제너레이터는 이터레이터를 리턴하는 함수이다 제너레이터를 통해 쉽게 이터레이터를 만들 수 있다 이 이터레이터는 이터레이터이자 이터러블인데, 이터레이터는 Symbol.iterator 를 가지고 있고, 이 심볼 이터레이터의 실행결과는 자기 자신이다. 그러니까 제너레이터는 well formed 이터레이터를 return 하는 함수이다 일반함수는 호출하면 끝까지 한번에 실행되는데, 제너레이터 함수는 호출해도 바로 실행되지 않고, 이터레이터 객체를 반환한다 즉 실행 흐름은 이렇게 된다 yield 1은 대충 이런 뜻이다 => 일단 1을 밖으로 내보내고, 여기서 함수 실행을 멈춰 그리고 다음에 next()가 호출 되면 여기 다음 줄부터 다시 실행 그래서 yield는 return이랑 비슷하게 값을 밖으로 보내지만, 함수를 완전히 끝내지 않는다는 점이 다르다 # 자바스크립트에서는 이 제너레이터를 통해서 어떤 상태나 어떤 값이든 순회할 수 있게 만든다 ## 자바스크립트에서 제너레이터는 문장(statement)을 통해 순회할 수 있는 값을 만드는 문법이다 >> 여기서 문장은 if, for, while, yield처럼 코드의 실행 흐름을 만드는 statement를 말한다 일반적으로 문장은 어떤 동작을 실행하거나 흐름을 제어할 뿐, 그 자체가 값처럼 순회되지는 않는다 하지만 제너레이터를 사용하면 이런 문장들로 작성한 실행 흐름을 바탕으로, 값을 하나씩 꺼낼 수 있는 이터러블을 만들 수 있다 예를 들어 제너레이터 함수 안에서 조건문을 사용하면 특정 조건일 때만 값을 내보낼 수 있고, 반복문을 사용하면 반복하면서 값으 순차적으로 내보낼 수 있다 이때 yield는 값을 밖으로 내보내면서 함수 실행을 잠시 멈추는 역할을 한다 즉, 제너레이터는 배열처럼 이미 만들어진 값을 순회하는 것뿐만 아니라, 문장으로 작성한 로직을 실행하면서 필요한 값을 하나씩 만들어 순회할 수 있게 해준다 ## 정리하자면, 제너레이터는 문장을 값으로 만들 수 있게 해주는 도구다. 더 정확히는 if, for, while 같은 문장으로 구성된 실행 흐름을 순회 가능한 값, 즉 이터러블로 바꿔주는 문법이라고 볼 수 있다
